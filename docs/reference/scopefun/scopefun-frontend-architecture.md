# ScopeFun 前端信号链架构分析

> 分析对象：`Scopefun原理图.pdf`（21 页）。前端在 p2–p5，四通道完全相同，本文以 p2 的**通道 4** 为准，位号后缀 `_4`。支撑电路取自 p10（偏置与失调）和 p13（前端电源）。
>
> PDF 为纯矢量图、文字已转曲，本文全部结论由渲染后逐页读图得出，**器件规格未经数据手册核实**。

四通道相同的模拟前端，从 BNC 到 ADC 共四级。核心是 **BUF802 与 OPA140 组成的混合路径缓冲**——它把 AC/DC 耦合切换从射频通路挪到了低频通路，因此一颗 CMOS 模拟开关就够，不需要射频继电器。

## 信号链总览

四级串联，每一级由一个继电器或一颗芯片主导。级号是真实的信号顺序。

| 级 | 名称 | 主器件 | 作用 |
|---|---|---|---|
| **1** | 端接与阻抗切换 | `K1000_4` UD2-4.5NUN-L | DPDT 继电器选路 + 汇合，50 Ω 端接或 1 MΩ 高阻 |
| **2** | 50× 衰减器 | `K1001_4` + 976k/20k | 1× 直通或 50× 分压，多阶补偿网络 + 可调微调电容 |
| **3** | 混合缓冲与 AC/DC | `BUF802` + `OPA140` + `TMUX4053` | 高频走 JFET，低频走精密运放，AC/DC 在低频路径切换 |
| **4** | 可编程增益 | `LMH6518` | 单端进差分出，失调由 DAC 从 IN_N 注入 |

四级之后是 ADC Driver（p6–p9）与 ADC（p11），对频率计不适用，本文不展开。

## Stage 1 端接与阻抗切换

> Termination and Attenuation · `K1000_4` · 原理图：[`p2_term_L.png`](./p2_term_L.png)

### 信号路径

```
J1002_4 (BNC) ── BNC_IN ── K1000_4A pin3 (COM)
                              │
   ┌──[pin4] TERM_50Z ────────┴──┬── R1025_4  49.9Ω ── GND      (50 Ω 端接)
   │                             │
   │                             └── R1021_4  15Ω ────┬── TERM_50Z_R ── K1000_4B pin5
   │                                 C1058_4 18pF ────┘
   │                                 + R1053_4 0Ω  (与 15Ω 并联)
   │
   └──[pin2] TERM_1M ── R1022_4 30Ω ── TERM_1M_R ────────────── K1000_4B pin7
                                       C1022_4 (DNP) ── GND
                                                                      │
                                                    K1000_4B pin6 (COM) ── ATTEN_IN
```

一颗 DPDT 继电器用掉两组触点：**A 组选路、B 组汇合**。这是双通路架构的标准用法——两组触点同步动作，保证输入端和输出端永远选中同一条路径。

### 元件

| 位号 | 值 | 作用 |
|---|---|---|
| **R1025_4** | 49.9 Ω | 50 Ω 档的端接电阻，接在继电器输出侧、限流电阻之前 |
| **R1021_4** | 15 Ω | 50 Ω 路径的串联阻尼／限流 |
| C1058_4 + R1053_4 | 18 pF + 0 Ω | 并联在 15 Ω 两端做高频旁路，抵消它在高频段的插损。容抗等于 15 Ω 的频点约 590 MHz |
| **R1022_4** | 30 Ω | 1 MΩ 路径的串联限流保护。相对 1 MΩ 可忽略，故障时限制冲入后级的电流 |
| C1022_4 | DNP | 预留位，不贴 |

### 继电器驱动值得单独看

```
+VUSB ──┬── R1027_4 22Ω ──┬────────── pin1 (线圈+)
        │                  │
   C1026_4 22µF        C1027_4 22µF     C1009_4 1µF
        │                  │                 │
       GND                GND               GND

pin8 (线圈−) ──┬── D1000_4 (1N4148WT-7) ── +VUSB   续流
               └── Q1002_4 (DMN62D0UW) ── GND

TERMD ──┬── R1029_4 10K ── Q1002_4 栅极
        └── R1031_4 10K ── GND                      栅极下拉
```

**22 Ω 串联 + 44 µF 储能**——切换瞬间由大电容放电提供吸合所需的大电流，稳态时 22 Ω 限制保持电流。既降低了对 +VUSB 的冲击，又减少了线圈持续发热带来的热漂移。

**栅极 10 K 下拉（R1031_4）**——控制信号悬空或上电未初始化时，MOS 确定关断，继电器状态不会不确定。四个通道八个继电器每一个都配了下拉。

## Stage 2 50× 衰减器

> 50x Attenuator · `K1001_4` · 原理图：[`p2_term_R.png`](./p2_term_R.png)

只有 **1× 和 50× 两档**，没有 10×、没有 100×。这印证了通用做法：衰减档是保护档，不是量程档——量程由后面 LMH6518 的可编程增益和失调 DAC 承担。

### 分压与补偿网络

```
ATTEN_IN ── K1001_4A pin3 (COM)
              ├──[pin4] ATTEN_1X ─────────────────── K1001_4B pin5
              │                                              │
              └──[pin2] ATTEN_50X_IN                         │
                          │                                  │
                          ├── R1001_4 1K ── C1011_4 3pF ── GND   (输入阻尼)
                          │
                          ├── R1024_4 976k ─────────────┬── ATTEN_50X_OUT ── pin7
                          │                             │
                          ├── C1023_4 3pF ──┐           ├── R1026_4  20k    ── GND
                          │                 ├── M ──────┤   C1021_4  3pF    ── GND
                          └── C1012_4 0.3pF │           └── C1059_4  2–6pF  ── GND  ★可调
                              └ R1002_4 976k┘
                                    M ── C1025_4 8pF ── GND
                                    M ── C1024_4 1pF ── ATTEN_50X_OUT
                                                                  │
                                             K1001_4B pin6 (COM) ── ATTEN_OUT
```

直流分压比由主链决定：

```
20k / (976k + 20k) = 1/49.8 ≈ 1/50
```

高频段则由电容网络决定。`C1012_4 0.3pF`、`C1023_4 3pF`、`C1024_4 1pF`、`C1025_4 8pF` 与 `R1002_4 976k` 构成的中间网络，是在基本的两元件补偿之外再加的**多阶极点／零点整形**，用来把过渡区的响应压平。这比教科书上的「上下臂各并一颗电容」复杂得多，是宽带衰减器做到平坦的实际代价。

### 两个工程细节

- `C1059_4` 是 **2–6 pF 可调电容**，装在下臂。杂散电容量产不可控，补偿必须留一个可调元件，出厂用方波逐档校准——和示波器探头上那颗补偿螺丝是同一回事。
- 衰减器区域盖了**金属屏蔽罩**：`SHLD1000_4`（TE 2118727-2）和 `SHLD1001_4`（TE 2118728-2，DNP 预留）。高阻抗节点必须屏蔽。

## Stage 3 混合缓冲与 AC/DC 耦合

> Input Buffer and AC/DC Coupling · `BUF802` + `OPA140` + `TMUX4053` · 原理图：[`p2_buf.png`](./p2_buf.png)

整个前端最精彩的一级。BUF802 是双路径器件：**高频走内部 JFET 缓冲，低频和直流走外部精密运放经 Aux 输入注入**。两条路径在芯片内部合并，输出既有 JFET 的带宽，又有精密运放的直流精度。

### 双路径结构

```
                        ┌── 高频路径 ───────────────────────────┐
ATTEN_OUT ── R1035_4 30Ω ── ATTEN_OUT_R ── C1030_4 1nF ── BUF_IN ──┤ pin2  IN
    │                                                              │
    │                          R1038_4 10M ── BUF_IN_BIAS ─────────┤ pin3  IN_Bias
    │                                                              │
    │                   ┌── 低频/直流路径 ──┐                       │  BUF802
    ├── R1039_4 909k ───┤                   │                      │  U1009_4
    │                   ├─ C1031_4 10nF ─┐  │                      │
    ├── R1047_4 90.9k ──┘   (可被短路)   │  │                      │
    │        │                           │  │                      │
    │       GND                          ▼  │                      │
    │                            OPA140 U1011_4 (+)                │
    │                            DC_FB ────── (−)                  │
    │                                    │                          │
    │                              OPA_OUT ── R1043_4 2K ──────────┤ pin4  IN_Aux
    │                                         C1035_4 100pF ∥       │
    │                                         C1034_4 100pF ── GND  │
    │                                                               │
    │                              R1036_4 35.7k ── −5V ────────────┤ pin7  R_Bias
    │                                                               │
    └───────────────────────────────────────── BUF_OUT ◄────────────┤ pin11 OUT
                                                   │
              DC 伺服：BUF_OUT ── R1041_4 90.9k ── R1042_4 90.9k
                                       └── R1044_4 10K ── DC_FB ──► OPA140 (−)
```

### AC/DC 切换在低频路径上完成

**这是本次分析最有价值的发现。** 主高频路径上的 `C1030_4 1nF` 是**固定隔直电容，永不切换**——因为高频路径本来就只传交流，直流分量完全由 Aux 路径提供。于是 AC/DC 切换只需要在低频路径上做，而那条路径是高阻、低频的，**一颗 CMOS 模拟开关就够，完全不需要射频继电器。**

| 耦合方式 | `DC_CPLD` | TMUX4053 动作 | 效果 |
|---|---|---|---|
| **DC 耦合** | 1 | S1B–D1 导通，短路 `C1031_4`；S2B/S3B 接入 `C1002_4 68pF` | OPA140 直接看到分压后的直流，Aux 路径传递直流分量 |
| **AC 耦合** | 0 | S1A–D1 导通（S1A 悬空即断开），`C1031_4 10nF` 串入；S2A/S3A 接入 `C1001_4 100pF` | OPA140 看不到直流，输出中直流分量被消除 |

#### 交越补偿随耦合方式一起切换

注意上表第三列的后半段：AC 耦合接 **100 pF**，DC 耦合接 **68 pF**，原理图上明确注了 *"This cap is switched in during AC / DC coupling"*。

原因是 AC 耦合时低频路径里串入了 `C1031_4 10nF`，改变了该路径的传递函数，两条路径的**交越频率**随之偏移，必须重新补偿才能保证合并后的响应平坦。`TMUX4053` 三组开关由同一根 `DC_CPLD` 同步驱动，一次动作同时完成耦合切换和补偿匹配。

### 直流精度靠伺服环路

输出 `BUF_OUT` 经 `90.9k / 90.9k / 10K` 分压得到 `DC_FB`，送回 OPA140 的反相输入。OPA140 比较输入分压与输出分压，通过 Aux 路径持续校正 BUF802 的直流输出——**整机的直流精度由 OPA140 这颗精密运放决定，而不是由 JFET 决定**。这正是混合架构存在的意义。

### 元件

| 位号 | 值 | 作用 |
|---|---|---|
| R1035_4 | 30 Ω | 进 BUF802 前的串联限流／阻尼（与 Stage 1 的 30 Ω 同一思路） |
| C1030_4 | 1 nF | 高频路径固定隔直，不参与 AC/DC 切换 |
| R1038_4 | 10 M | BUF802 的 IN_Bias 偏置电阻 |
| R1039 / R1047 | 909k / 90.9k | 低频路径分压，合计约 1 MΩ，分压比 1/11 |
| R1043_4 | 2 K | OPA140 输出到 IN_Aux 的串联电阻，与切换电容一起决定交越特性 |
| **R1036_4** | 35.7 k | R_Bias 到 −5 V，设定 BUF802 静态电流。图上注明约 **24 mA/rail**；换 100k 则降到约 17 mA/rail |
| U1001_4 | TMUX4053 | 三组 SPDT 模拟开关，±5 V 供电，EN 接地常使能，SEL1/2/3 全部并到 `DC_CPLD`，`R1052_4 10K` 下拉 |

## Stage 4 可编程增益放大

> Programmable Gain Amplifier · `LMH6518` · 原理图：[`p2_pga.png`](./p2_pga.png)

```
BUF_OUT ── R1037_4 49.9Ω ── BUF_OUT_R ──► pin6  IN_P        pin15 OUT_P ──► R52_4 0Ω ── OUT_P
                                                            pin14 OUT_N ──► R97_4 0Ω ── OUT_N
PGA_BIAS ───────────────────────────────► pin7  IN_N        pin13 VCM   ──► VCM
                                                            pin1/2/16 AUX_P / AUX_N / AUX_VCM ── 未使用
PGA_CSn  ──► pin9  CSn  (R1033_4 10K 上拉)
PGA_SDIO ──► pin10 SDIO                  电源：pin3/4 VCC ◄── +VPGA (+5V 经 FB1000_4 120Ω@100MHz)
PGA_SCLK ──► pin11 SCLK                        pin12 VDD ◄── +3V3_PGA
                                               pin5/8 GND, pin17 PAD ── GND
```

**单端驱动、差分输出。** LMH6518 的输入引脚是 `IN_P`／`IN_N` 一对，但用法是单端：信号经 49.9 Ω 进 `IN_P`，`IN_N` 接一个直流参考电平 `PGA_BIAS`。芯片放大的是两者之差。

### IN_N 就是失调／电平注入点

`PGA_BIAS` 由 `+VBIAS`（2.5 V 基准）经 `R1045_4 ∥ R1046_4`（1K ∥ 1K）与 DAC 输出的 `TRIM` 信号混合形成，`TRIM` 先过一颗 `FB1001_4 120Ω@100MHz` 磁珠再进来，`C1042_4 100nF` 滤波。

改变 `IN_N` 的电平，就等于移动了信号的参考零点。对示波器这是**垂直位置**；对频率计，这就是**触发电平**——而且是在放大之前设定的，DAC 的分辨率要求远低于在比较器端设阈值。

### 省电细节

原理图注明 *"Max VCC current before configuration (AUX output on): 0.225 A / after configuration turns off AUX output: 0.165 A"*。**ScopeFun 没有使用 AUX 输出**，并在 SPI 配置时主动关闭它，省下 60 mA。`J3_4`／`J4_4` 两个 UFL 座标为 DNP，看得出原本打算把 AUX 引出。

### 基准与失调 DAC（p10）

> 原理图：[`p10_trim.png`](./p10_trim.png)、[`p10_bias.png`](./p10_bias.png)

### 前端电源（p13）

> 原理图：[`p13_fe_pwr.png`](./p13_fe_pwr.png)

| 位号 | 器件 | 说明 |
|---|---|---|
| U15 | TPS7A9101 | **超低噪声 LDO**，+5V3 → +5 V（图上算得 5.01 V），软启动 13 ms（刻意大于前级的 6 ms）。注明 968 mA / 728 mA 两个负载点 |

## 七个值得借鉴的手法

### 1. 把 AC/DC 切换挪出射频通路

混合路径架构下，直流分量只走低频支路，所以耦合切换也只需在低频支路上做。一颗 TMUX4053 取代了射频继电器和大体积高压隔直电容——这是 BUF802 架构带来的最大结构性简化。

### 2. 补偿参数跟着工作模式一起切换

AC 与 DC 两种耦合下，两条路径的交越频率不同，于是交越补偿电容也跟着切（100 pF / 68 pF），由同一根控制线同步完成。只切信号不切补偿，响应就会在交越区出现凸起或凹陷。

### 3. 继电器的储能式节能驱动

22 Ω 串联加 44 µF 储能：吸合瞬间靠电容放电供大电流，稳态靠电阻限流。既不冲击电源，又压低了线圈的持续发热——发热就是漂移。

### 4. 每个 MOS 栅极都有下拉

八个继电器驱动无一例外配了 10 K 下拉。控制器复位、上电未初始化、固件跑飞时，继电器状态都是确定的。

### 5. 衰减器必须留可调元件

2–6 pF 可调电容装在下臂。杂散电容随批次、布局、器件批号变化，补偿条件不可能靠固定值满足，出厂逐台校准是必经步骤。

### 6. 高阻节点要有金属屏蔽罩

衰减器区域盖 TE 屏蔽罩并预留第二个位置。976 kΩ 量级的节点上，几毫伏的空间耦合就是可观的误差。

### 7. 超低噪声 LDO + 磁珠分域 + 密集去耦

电源不是「能用就行」的部分。前端用 TPS7A9101 这类超低噪声 LDO，PGA 电源和 DAC 输出各经磁珠隔离，单通道近二十颗去耦电容。

## 对频率计前端的适配

ScopeFun 用的正是 **BUF802 + LMH6518** 组合，衰减档也正是 **1× / 50×** 两档。这为几个悬而未决的选型提供了实证。

### 可以直接搬过来的

| | 内容 |
|---|---|
| **直接抄** | **Stage 3 整块。** BUF802 + OPA140 + TMUX4053 的混合缓冲，含 AC/DC 方案、交越补偿切换、DC 伺服环路。这一块同时解决 1 mHz 直流精度需求和 500 MHz 带宽需求，还省掉原本要用 K3 继电器加两颗隔直电容的整套 AC/DC 电路 |
| **直接抄** | **Stage 1 的继电器用法与驱动。** 一颗 DPDT 分「选路 + 汇合」两组触点，与现有 K1 用法一致，确认方向正确。储能式驱动和栅极下拉直接补进电路 |
| **直接抄** | **LMH6518 的 IN_N 做电平注入。** ScopeFun 用它做垂直位置，频率计用它做触发电平，接法完全相同：基准电压经电阻网络与 DAC 输出混合，DAC 侧串磁珠。MCP4728 这类 4 通道 12 位 I²C DAC 就够用 |
| **直接抄** | **电源与偏置架构。** 超低噪声 LDO、REF2025 产生 ±2.5 V 基准、磁珠分域 |

### 必须为频率计改动的

| | 内容 |
|---|---|
| **要改** | **输出级完全不同。** ScopeFun 的 LMH6518 主输出经 0 Ω 送 ADC Driver 再进 ADC；频率计要送 ADCMP573 比较器。有意思的是 **ScopeFun 关掉不用的 AUX 输出，对频率计恰好是现成的比较器通道**——AUX_VCM 还能独立设定共模，正好匹配比较器的输入范围 |
| **要改** | **要补一级 100 kHz 低通。** 示波器不需要，所以 ScopeFun 全图没有；但 1 mHz 指标下噪声导致的重复触发是主要误差源，这一级必须自己加，且要用 Bessel 或一阶 RC，不能用 Chebyshev |
| **要改** | **衰减比按最大输入电压定。** ScopeFun 选 50×（976k/20k）。若最大输入定在 ±40 V 附近，10× 就够；要对齐示波器的 ±300 V 则需要 50× 或 100× |
| **要核** | **过压保护。** 这次读图没有看到明显的输入保护（TVS、箝位、过压检测跳闸）。可能在未细读的区域，也可能 ScopeFun 就是靠 30 Ω 限流加器件自身耐受。前端若要接用户任意信号，这一块不能照搬缺失 |

### 与本项目当前原理图的差距

| 环节 | ScopeFun | 本项目当前状态 |
|---|---|---|
| 阻抗切换 | K1000 DPDT，选路+汇合 | K1 同样用法，方向一致 |
| 衰减档 | 1× / 50×，单继电器选抽头 | 级联两组分压器 → 实际是 10×/100×，**缺 1× 档** |
| 缓冲器 | BUF802 + OPA140 混合 | OPA659 单路径，直流漂移是短板 |
| AC/DC | TMUX4053 在低频路径切换 | 计划用 K3 继电器 + 隔直电容，尚未实现 |
| PGA | LMH6518，IN_N 注入失调 | 已改用 LMH6518，**但整颗芯片尚未接线** |
| 触发电平 | MCP4728 → IN_N | 尚无 DAC 通路 |
| 低通滤波 | 无（示波器不需要） | 需自行增加（1 mHz 指标要求） |
